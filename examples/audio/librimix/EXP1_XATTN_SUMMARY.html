text-TSE 实验小结

时间分辨文本线索 + Cross-Attention（Exp1） · 2026-06-16 · Libri2Mix train-clean-100，BSRNN + 冻结 MiniLM-384，4×RTX4090D

一、背景与动机

此前三套方案（固定 13900 混音 baseline / 抗过拟合正则 / 在线动态混音）在测试集上均失败：训练集 swap gap ≈ 25 dB（机制成立），但测试集（unseen 说话人）上 oracle ≈ interferer ≈ 0 dB、接受率仅 3%——模型塌缩成 passthrough、无视文本。

根因诊断：旧文本线索是整句 mean-pool 成单个 384 维向量，等价于每条语句的「唯一指纹」。模型只需记住「这个向量 ↔ 见过的这条声源」的查表，无需学可泛化的「内容→说话人」对齐 → 不迁移到 unseen。

二、本轮方法（改了什么）

  • 线索表示：句向量 → 保留 MiniLM 每个 token 的 last_hidden_state（L×384 序列，恢复时间/序列维度）。
  • 融合方式：时间不变的 multiply → 在 BSRNN 子带特征上做 cross-attention（音频帧作 Query，文本 token 作 Key/Value），让模型逐帧对齐「哪个词对应哪段声学」。
  • 工程：变长 token 的 padding + key_padding_mask、cue 路由、合成张量 smoke 测试（形状/掩码/文本敏感性）全部通过。

三、训练过程

不稳定 → 已解决。 直接用 lr 1e-3、无 warmup 时，cross-attention 在 ~ep5 起震荡发散（train loss 冲到 0.2、始终不下负）。改为 warmup 5 epoch + lr 3e-4 + clip 1.0 后训练平滑稳定。

损失为 auraloss SISDRLoss = −SI-SDR：越负越好，≈0 为 passthrough，正值比 passthrough 更差。

四、评估：test swap（关键判决）

swap test：同一测试混合跑两遍——给 oracle 文本（目标转写）vs interferer 文本（干扰者转写），均以目标为参考打分。用对文本应能提取、用错文本应失败；二者差距（gap）= 模型是否真在「用文本选人」。

五、结论

一句话：cross-attention 的方向是对的、能训、且比 baseline 明显更「会用文本」，但端到端只用 SI-SDR 仍训不出泛化的干净提取，会过拟合。
  • ✅ 能训：warmup 解决了不稳定，train loss 稳定下负。
  • ✅ 更 text-aware：测试接受率 3% → 12–24%；oracle 始终 > interferer，且 gap 随训练增大（0.28 → 0.69 dB）——换错文本性能稳定变差，证明模型确实在用文本选人。
  • ❌ 不泛化：oracle 平均 SI-SDRi ≈ 0（unseen 说话人上即使给对文本也提不出），与 baseline 同样的墙；同时过拟合（train −2 / val +0.7）。

解读：时间分辨 cross-attention 比单个句向量更能抓到文本信号，但「端到端仅 SI-SDR」的监督太弱/太间接，不足以让注意力学出可泛化的「内容→说话人」对齐——模型一边变得更 text-aware、一边过拟合。

六、下一步

同任务参考工作 DAE-TSE（同样 keyword/transcript-guided TSE + BSRNN + WeSep + cross-attention，达 16 dB SI-SDRi / 98% 接受率）的差异恰好指出缺口，且与本轮数据自身的指向一致：

  • 音素 cue（G2P）替代 MiniLM 句/词向量——音素与声学直接对齐、词表有限、train/test 复现，覆盖更好。
  • 给线索路径加辅助监督：ASR(CTC) + 说话人验证（其消融显示去掉 CTC：16.45 → 3.47 dB）——给 cross-attention 直接的「内容对齐 + 选人正确」梯度，这是端到端 SI-SDR 给不了的。
  • 两阶段（先训线索编码器、冻结、再训分离骨干）——同时解决监督不足与训练不稳。
